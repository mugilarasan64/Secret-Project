BIRTHDAY SURPRISE WEBSITE — CLEAN FULL PACKAGE

1. Open index.html to preview locally.
2. Upload the contents of this folder to the root of your GitHub Pages site.
3. Keep index.html, style.css, script.js, and the assets folder together.

ASSETS FOLDER
The assets folder is intentionally left empty for you to add your own files.
The website expects these paths (use the exact names, or update the paths in
index.html and script.js if you choose different names):

Background / playlist track 01:
  assets/November-Angel-Short.mp3
Cover for track 01:
  assets/covers/November-Angel-Short.jpg

Playlist track 02:
  assets/songs/November-Angel.mp3
Cover for track 02:
  assets/covers/November-Angel.jpg

Playlist track 03:
  assets/songs/Birthday-Bujji.mp3
Cover for track 03:
  assets/covers/Birthday-Bujji.jpg

Create the covers and songs subfolders inside assets when adding your files.
The separate music page uses the same background audio element, so navigation
between the letter and playlist does not intentionally restart playback.

MUSIC PLAYER ALIGNMENT
The music control buttons have isolated sizing, margin, padding, and flex rules
to prevent global button styles from shifting Play/Pause/Previous/Next controls.
